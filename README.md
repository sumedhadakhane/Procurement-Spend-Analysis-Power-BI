# Problem Statement
Procurement teams often lack visibility into purchasing patterns, PO status, and supplier performance, leading to inefficiencies, overspending, and poor supplier decisions. Disconnected data prevents strategic analysis of packaging types, item-level trends, and vendor contributions.

This project addresses these issues by developing an interactive Power BI dashboard that tracks procurement KPIs, visualizes buying trends, and highlights top suppliers and stock items.

# Actions Taken
•	Cleaned and standardized procurement data 

•	Created DAX Measures like Total Purchases, Total PO, Order Quantity, Final/Non-Final PO, Order & Received Outers.

•	Visualized procurement trends by packaging and color, tracked monthly performance, and ranked top suppliers and items based on spend and volume.

•	Enabled filters by supplier, date, and packaging type for flexible insights.

•	Identified high-spend areas, supplier dependency, and frequently ordered items.

# Conclusion
The dashboard offers clear, real-time insights into procurement activity, helping teams:
•	Optimize supplier strategies and packaging decisions

•	Improve visibility into PO lifecycle and item-level trends

•	Reduce manual reporting time and support cost-saving initiatives
